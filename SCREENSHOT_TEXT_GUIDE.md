## 🎨 Design Tips for Text Overlays

### Typography:

- **Main headline:** Bold, 32-40px, white or brand color
- **Subheadline:** Regular, 18-24px, white or light gray
- **Body text:** Regular, 14-18px, white or light gray

### Colors (Match Your Brand):

- **Primary green:** `#2ecb73` (for highlights)
- **White:** For main text
- **Black/Dark:** For backgrounds with white text

### Placement:

- **Top third:** For headlines (doesn't cover important UI)
- **Bottom third:** For call-to-action or feature lists
- **Left/Right edges:** For feature highlights
- **Center:** Only if it doesn't cover key content

### Text Style Examples:

**Bold & Direct:**

```
AI Football Analysis
Ask. Analyze. Win.
```

**Benefit-focused:**

```
Make Smarter Decisions
With Data-Backed Insights
```

**Feature-focused:**

```
Complete Match Intelligence
In Your Pocket
```

## 💡 Pro Tips

1. **First Screenshot is Critical** - This is what users see in search results. Make it count!

2. **Show Real Content** - Use actual screenshots from your app, not generic mockups

3. **Keep Text Minimal** - Don't overcrowd. Let the app speak for itself

4. **Highlight Unique Value** - Emphasize "data patterns, not opinions" - your differentiator

5. **Include Social Proof** - If you have user count or ratings, mention them:

   ```
   Trusted by 10,000+ fans
   ```

6. **Test Readability** - Ensure text is readable on small screens (phone preview)

7. **A/B Test** - Try different text on different screenshots to see what converts
